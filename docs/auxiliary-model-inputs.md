# Auxiliary model inputs

A frozen forecast model can supply expected return, downside probability or a
risk/regime estimate to the trading policy. The policy would combine those
coordinates with market/account state to choose exposure and protections. This
is technically feasible; no defensible probability of improving trading returns
is available from current evidence. The completed residual-boosting proposal
failed and stays closed; it must not be repackaged as a new input.

## Causal training contract

An upstream predictor trained on all training labels must not generate in-sample
features for the downstream learner. Use chronological expanding-window or
blocked cross-fitting: each training feature is generated by a predictor fitted
only on labels already completed before that decision. Purge overlapping forecast
horizons at every boundary. Preprocessing and calibration follow the same rule.
Store predictor identity, training cutoff, horizon, public availability time and
prediction timestamp with each output. Freeze the final training-only predictor
for validation and inference. Do not fit it to validation or retired-test labels.

## Admission and evaluation

A new predictor requires a distinct preregistered hypothesis and training-only
predictive/calibration checks against simple baselines. A passed forecast gate
is necessary evidence, not a trading-return guarantee. Then compare a masked
input control and frozen-signal candidate with identical policy capacity, costs,
sampling and checkpoint rules. Include strong SAC and matched stock/ETF holding,
selected/final results, multiple seeds, drawdown and short-side diagnostics.
Prospective shadow evaluation remains required before promotion.

Use cached predictions and sparse progress summaries for token/memory efficiency.
Checksum predictor, preprocessing and feature schema in the frozen policy bundle;
reject mismatches and stale inputs. Benchmark inference cost before Colab screens.
No new auxiliary predictor or performance allocation is enabled by this document.
